Sensors Fundamentals

ความรู้เบื้องต้นเกี่ยวกับเซ็นเซอร์ และ KY-025 Magnetic Reed Switch Sensor

เซ็นเซอร์เป็นอุปกรณ์ที่ตรวจจับการเปลี่ยนแปลงของสภาพแวดล้อม แล้วแปลงข้อมูลให้เป็นสัญญาณไฟฟ้า เพื่อให้ไมโครคอนโทรลเลอร์ เช่น Arduino ประมวลผลและทำงานต่อไปได้

ความรู้เบื้องต้นเกี่ยวกับเซ็นเซอร์

Sensor หรือเซ็นเซอร์ ทำหน้าที่เป็นประสาทสัมผัสของระบบอิเล็กทรอนิกส์ โดยจะตรวจจับสิ่งแวดล้อม เช่น แสง อุณหภูมิ ความชื้น ระยะทาง การเคลื่อนไหว สนามแม่เหล็ก หรือสถานะเปิด/ปิดของอุปกรณ์ต่าง ๆ แล้วส่งสัญญาณออกไปยังไมโครคอนโทรลเลอร์เพื่อประมวลผล

หน้าที่ของ Sensor

  1. ตรวจจับค่าจากสภาพแวดล้อม
  2. ส่งสัญญาณไฟฟ้าออกมา
  3. ไมโครคอนโทรลเลอร์อ่านค่า
  4. ประมวลผลและตัดสินใจ
  5. สั่งงานอุปกรณ์ต่อไป

ตัวอย่างการใช้งาน

  • ตรวจจับว่าประตูเปิดหรือปิด
  • ตรวจจับว่ามีแม่เหล็กเข้ามาใกล้หรือไม่
  • ตรวจจับความสว่างหรือความชื้น
  • ใช้เป็นตัวรับข้อมูลสำหรับระบบอัตโนมัติ

ประเภทของสัญญาณจาก Sensor

Digital Sensor

ให้สัญญาณแบบ 2 สถานะ คือ HIGH หรือ LOW เหมาะสำหรับงานที่ต้องการรู้เพียงว่ามีหรือไม่มีเหตุการณ์เกิดขึ้น

  • กดปุ่ม
  • ประตูเปิด/ปิด
  • ตรวจจับแม่เหล็ก

Analog Sensor

ให้สัญญาณแบบต่อเนื่องตามแรงดันที่เปลี่ยนแปลง โดย Arduino UNO อ่านได้เป็นค่า 0 ถึง 1023

  • ความสว่างจาก LDR
  • ความชื้นในดิน
  • แรงดันจาก Sensor หลายชนิด

ค่าที่ควรรู้ก่อนใช้งาน Sensor

รายการ ความหมาย
Operating Voltage แรงดันไฟเลี้ยงที่ Sensor รองรับ เช่น 3.3V หรือ 5V
Output Type ชนิดสัญญาณ เช่น Digital, Analog, I2C, SPI หรือ UART
Pinout ตำแหน่งและหน้าที่ของขาแต่ละขา
Detection Range ระยะหรือช่วงค่าที่ Sensor ตรวจจับได้
Response Time เวลาที่ Sensor ใช้ตอบสนองต่อการเปลี่ยนแปลง
Calibration การปรับค่าเพื่อให้ Sensor อ่านค่าได้เหมาะสม

KY-025 Magnetic Reed Switch Sensor Module

KY-025 เป็นโมดูลสำหรับตรวจจับสนามแม่เหล็กแบบ Reed Switch เหมาะสำหรับตรวจจับการเปิด/ปิดประตู หน้าต่าง หรือตำแหน่งชิ้นงานที่มีแม่เหล็กเข้าใกล้

ชื่อโมดูล KY-025 Magnetic Reed Switch Sensor
แรงดันใช้งาน 3.3V - 5V
เอาต์พุต Digital Output และ Analog Output
ขา หน้าที่ การต่อกับ Arduino UNO
G / GND Ground GND
+ / VCC ไฟเลี้ยงโมดูล 5V
D0 / DO Digital Output Digital เช่น D3
A0 / AO Analog Output Analog เช่น A0

หลักการทำงาน

Reed Switch ประกอบด้วยแผ่นโลหะ 2 แผ่นอยู่ภายในหลอดแก้ว เมื่อมีแม่เหล็กเข้าใกล้ จะทำให้แผ่นโลหะแตะกันและปิดวงจร ทำให้โมดูลส่งสัญญาณออกทาง D0 หรือ A0 โดยวงจร LM393 จะเปรียบเทียบกับค่า Threshold ที่ตั้งด้วย Potentiometer

ตัวอย่างโค้ด Arduino

const int digitalPin = 3;
const int analogPin = A0;
const int ledPin = 13;

void setup() {
  pinMode(digitalPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int digitalValue = digitalRead(digitalPin);
  int analogValue = analogRead(analogPin);

  digitalWrite(ledPin, digitalValue);

  Serial.print("Digital: ");
  Serial.print(digitalValue);
  Serial.print(" | Analog: ");
  Serial.println(analogValue);

  delay(200);
}

การใช้งานที่เหมาะสม

  • ตรวจจับการเปิด/ปิดประตูหรือหน้าต่าง
  • ทำระบบแจ้งเตือนด้วยแม่เหล็ก
  • ตรวจจับตำแหน่งชิ้นส่วนที่เคลื่อนที่
  • ใช้เป็น Limit Switch แบบไม่สัมผัส
  • ตรวจจับชิ้นงานเมื่อมีแม่เหล็กอยู่ใกล้
  • ใช้งานร่วมกับ Arduino, ESP32 หรือ Raspberry Pi
  • มีทั้ง Digital Output และ Analog Output
  • เหมาะสำหรับงานตรวจจับสถานะเปิด/ปิดแบบง่าย
